# Stars

## What It Is

Stars is a short browser game: catch five stars within five seconds, then face an intentionally surprising jumpscare.

## Features

- Five-second timer and score display.
- Randomly positioned star targets.
- Full-screen jumpscare image, sound, and screen flashing.
- Vibration support on compatible Android devices.
- Responsive game layout.

## Usage

Open `index.html`, press **Start Game**, and click all five stars before the timer ends. The jumpscare is part of the game and includes sudden audio and visual effects.

## Technology

HTML5, CSS3, vanilla JavaScript, local image assets, and an audio asset. No backend is required.

## Privacy and Safety

The game does not transmit data or use trackers. It includes sudden sound, flashing visuals, and a jumpscare; users with photosensitivity, sound sensitivity, or seizure risk should avoid it or disable the experience before playing.
