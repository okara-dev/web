# Stars

Ein Mini-Browserspiel mit einem unerwarteten Ende.  
Fange alle **5 Sterne in 5 Sekunden** – aber sei auf den letzten Klick gefasst. 💀

## Spielablauf

- Klicke auf **SPIEL STARTEN**
- Fange 5 Sterne, bevor die Zeit abläuft
- Der 5. Stern löst einen **Jumpscare** aus

## Features

- 5-Sekunden-Timer
- Zufällig erscheinende Sterne
- Jumpscare mit Vollbild-Bild
- Sound mit sofortiger Wiedergabe
- Vibration (Android)
- Flackern (weiß/schwarz)

## Nutzung 
1. index.html im Browser öffnen (Doppelklick reicht).
2. Spiel starten
3. Jumpscare kommt!

## Tech

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)

## Datenschutz

Alles läuft lokal. Keine Server, keine Tracker, keine Daten verlassen deinen Browser.

Wichtige Hinweise:

- Kein echter Schutz: Das Passwort und die Keys liegen im localStorage und sind mit Browser-DevTools auslesbar. Base64 ist keine Verschlüsselung, nur Verschleierung.
- Nur lokal: Bei gelöschtem Browser-Speicher sind die Keys weg. Nutze für kritische Keys ein echtes Passwort-Management.
