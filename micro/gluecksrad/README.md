# Gluecksrad

## What It Is

Gluecksrad is a customizable browser wheel that selects one value at random.

## Features

- Add up to 12 custom values.
- Automatically distribute values around a colorful canvas wheel.
- Realistic easing animation with winner display.
- Sound effects through Web Audio API and a confetti celebration.
- Edit the title and load example values.
- Persist title and values in local storage.
- Keyboard support for adding values and saving the title.

## Usage

Open `index.html`, edit the title if needed, add values, and press **Spin**. Use the reset button to remove stored values. Press Enter in an input to confirm it.

## Technology

HTML5 Canvas, CSS3, vanilla JavaScript, Web Audio API, Web Animations API, and `localStorage`.

## Privacy and Safety

Values and the title remain in the browser. No server or tracker is used. Do not use the wheel as a source of legally binding or safety-critical decisions.
