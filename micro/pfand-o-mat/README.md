# Pfand-O-Mat

## What It Is

Pfand-O-Mat is a local bottle-deposit counter with a savings goal and progress indicator.

## Features

- Increase or decrease the bottle count.
- Calculate the deposit value at EUR 0.25 per bottle.
- Set a bottle-based savings goal.
- Display percentage progress toward the goal.
- Persist the counter and goal in local storage.
- Reset the counter or permanently clear all stored data with confirmation.

## Usage

Open `index.html`, count bottles with `+1` and `-1`, set a goal, and monitor the progress bar. Use the reset controls when required.

## Technology

HTML5, CSS3, vanilla JavaScript, and `localStorage`. No backend or build tool is required.

## Privacy and Safety

All data remains in the browser and no tracker or server is used. Clearing browser storage or using the hard reset removes the saved counter and goal.
