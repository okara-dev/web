# Cake

Vergiss nie wieder einen Geburtstag. Kalender-Ansicht, Gruppen und ein Geburtstagsseiten-Generator, mit dem du personalisierte Seiten für Freunde und Familie erstellen kannst.

## Features

- Geburtstage hinzufügen (Name, Datum, Gruppe, Notiz)
- Kalender-Ansicht mit allen 12 Monaten
- Gruppen (Familie, Freunde, Arbeit, Sonstiges) – farblich markiert
- Heute-Highlight mit Puls-Animation
- Hover-Tooltip zeigt Geburtstage an einem Tag
- Geburtstagsseiten-Generator:
  - Personalisierte Nachricht, Wünsche, Absender
  - Alters-Anzeige
  - Interaktives "Geschenk öffnen"
  - 3 Templates (Konfetti, Elegant, Retro)
  - Download als .html-Datei – verschickbar per WhatsApp/E-Mail
  - Läuft offline, kein Server nötig
- Alle Daten lokal in localStorage
- Voll responsive
- Deutsch

## Nutzung

1. index.html im Browser öffnen
2. Geburtstag hinzufügen (Name, Datum, Gruppe)
3. Im Kalender auf einen markierten Tag klicken – der Generator öffnet sich
4. Nachricht, Wünsche und Absender eintragen
5. Template wählen – die Vorschau aktualisiert sich live
6. Download .html – Datei an die Person verschicken

### Der Generator

Die generierte Geburtstagsseite:

- Läuft komplett offline (eine einzelne HTML-Datei)
- Enthält Konfetti-Animation
- Zeigt Alter, Nachricht und Wünsche
- Hat einen "Geschenk öffnen"-Button mit Überraschung
- Funktioniert auf jedem Gerät (Handy, Tablet, PC)

Perfekt für WhatsApp, E-Mail oder als Link.

### Templates

- Konfetti – bunt, verspielt, pastell
- Elegant – dunkel, gold, edel
- Retro – warm, verspielt, 90er-Vibe

## Tech

- HTML5
- CSS3 (Grid, Animationen, Gradients)
- Vanilla JavaScript (ES6+)
- localStorage für Persistenz

## Datenschutz

Alles läuft lokal. Keine Server, keine Tracker, keine Daten verlassen deinen Browser.
