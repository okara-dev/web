# Cake

## What It Is

Cake is a local birthday calendar and personalized birthday-page generator. It helps you track birthdays and create a standalone page that can be shared by email or messaging apps.

## Features

- Add birthdays with names, dates, groups, and notes.
- View a full 12-month calendar with today highlighting and birthday tooltips.
- Generate personalized birthday pages with messages, wishes, sender, age, and gift-opening interaction.
- Choose Confetti, Elegant, or Retro templates.
- Download a self-contained HTML birthday page.
- Responsive design and local browser persistence.

## Usage

Open `index.html` in a browser, add a birthday, select a highlighted date, fill in the birthday page fields, choose a template, and download the generated HTML file.

## Technology

HTML5, CSS3, vanilla JavaScript, CSS animations, and `localStorage`. No build tool or backend is required.

## Privacy and Safety

Birthday data stays in the browser's local storage. No server or tracker is used. Do not include private details in a generated page unless you are comfortable sharing the downloaded file.
